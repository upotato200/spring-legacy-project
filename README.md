# 조달청 전자제안 심사 시스템 기능 요약

---

## 1. 로그인 페이지
이메일 형식의 ID와 비밀번호로 로그인. 역할(일반 사용자 / 심사위원 / 관리자)에 따라 접근 가능한 메뉴가 달라짐.

---

## 2. 대시보드 (관리자)
제안서 접수 및 심사 현황을 한눈에 파악.

| 구성 요소 | 설명 |
|---|---|
| 총 제안서 접수 건수 | 누적 제출 건수 집계 |
| 심사 완료/진행 중 건수 | 상태별(접수→심사중→완료/반려) 현황 |
| 탐지율 그래프 | 카테고리(IT/환경/경영 등)별 분포 시각화 |
| 최근 접수 이력 리스트 | 제안서 제목·제출자·상태 테이블 |

---

## 3. 사용자 관리 페이지 (관리자 전용)
가입된 사용자(제안자/심사위원) 목록 조회 및 계정 활성화·비활성화 처리.

- 비활성화 계정은 로그인 및 제안서 제출 차단
- 심사위원 계정 생성·수정·삭제 포함

---

## 4. 악성코드 DB 관리 페이지 → **제안서 관리 페이지**
등록된 제안서 목록을 통합 관리.

- **조회**: 전체 제안서 목록 (제목·제출자·카테고리·상태 검색)
- **심사위원 배정**: 제안서별 심사위원 지정
- **삭제**: 개별 제안서 제거
- **엑셀 내보내기**: 전체 제안서 일괄 다운로드
